# Alchemist's Profanity Censor

A lightweight, high-performance open-source Minecraft plugin designed to reduce the amount of swearing and profanity in your server chat.

## Features

* **Lightweight & Fast.** Optimized to filter messages instantly without causing server lag.
* **Open Source.** Fully transparent code, open for contributions and community audits.
* **Multi-Language Support.** Built-in detection for multiple languages and dialects.

## Supported Languages

* 🇷🇺 **Russian**
* 🇺🇸 **English (US)**
* 🇬🇧 **English (UK)**

## Compatibility

* **Target Versions:** Tested and fully compatible with Minecraft **1.21.1** up to the latest release.
* **Confirmed Stable:** Extensively tested on **1.21.11**.

## Installation

1. Download the latest `.jar` file from the [Releases](https://github.com/AlchemistSlime/Alchemist-s-Profanity-Censor) page.
2. Drop the file into your server's `plugins` folder.
3. Restart or reload your server to generate the configuration files.
